# SnapSolve AI

AI-powered study assistant for students using OpenRouter and Gemma 4.

## Features
- Ask study questions across General, Math, Physics, and English
- Get detailed exam-style explanations or quick short answers
- Urdu explanation mode
- Dark/light theme toggle, voice input, and local history panel

## Tech Stack
- Python Flask (backend)
- HTML/CSS/JavaScript (frontend)
- Gemma 4 via OpenRouter API

## How to Run
1. Clone this repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Create a `.env` file:
   ```env
   OPENROUTER_API_KEY=your_api_key_here
   ```
4. Start the app:
   ```bash
   python app.py
   ```
5. Open `http://127.0.0.1:5000` in your browser.
