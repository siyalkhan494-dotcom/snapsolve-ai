# SnapSolve AI

AI-powered study assistant using Google's Gemma 4 model.

## Features
- Ask study questions in Math, Physics, English
- Get detailed step-by-step explanations
- Quick "Short Answer" mode
- Clean dark-mode UI

## Tech Stack
- Python Flask (backend)
- HTML/CSS/JavaScript (frontend)
- Gemma 4 via OpenRouter API

## How to Run
1. Clone this repo
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.env` file with your OpenRouter API key
4. Run: `python app.py`
5. Open: http://127.0.0.1:5000
